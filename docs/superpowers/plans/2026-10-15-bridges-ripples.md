# R3 bridges and ocean ripples on the sim clock: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bridge decks from OSM in scene packages (CIGI and DIS solid, IR-correct), and ocean ripples driven by the sim clock.

**Architecture:** A new scene-package layer `features/bridges/` (3D Tiles 1.1) built in the main process from R2's cached OSM
features: deck heights from the bare-earth terrain at grounded ends (harmonic solve over the bridge graph), a swept
cross-section per way, piers. At runtime one more tagged Cesium tileset (`CamSimBridges`), a "feature tileset" notion
shared with the buildings, and a deck ceiling in the DIS surface probe. Ripples: three phases wrapped in double on the
CPU, written to `MPC_Ocean.RipplePhase`, read by `CamSimOcean.ush`; assets regenerated by script.

**Tech Stack:** Python 3 (numpy, shapely, rasterio; `uv run --project scripts/scene`), UE 5.8 C++ (Automation tests),
HLSL (`.ush`), UE Python commandlet for the ocean assets.

**Spec:** `docs/superpowers/specs/2026-10-15-bridges-ripples-design.md`

## Global Constraints

- A package without `[bridges]` builds byte-identical to today (every layer).
- Bridges: `MIN_CLEARANCE_M` = 2.0, `DECK_THICKNESS_M` = 1.5, `PARAPET_W_M` = 0.3, `PARAPET_H_M` = 1.0,
  `PIER_SPACING_M` = 30, piers only where clearance ≥ 3 m and ≥ 10 m from both ends, stations every ≤ 10 m, profile
  sample every 5 m, z13 tiles, geometric error 60, root content-less, ADD refinement.
- Runtime: `scene.bridges.enabled` true, `maximum_screen_space_error` 64, `maximum_cached_bytes_mb` 128,
  `create_physics_meshes` true; tag `CamSimBridges`; `DeckStepUpM` = 3.0.
- Ripple λ = 0.6 / 1.3 / 2.7 m, ω = √(g k), g = 9.80665, phase = −ω t wrapped to [0, 2π).
- `TMPDIR=/opt/mac/tmp` on every command; one CamSim at a time; `run.sh` in the foreground or with `pipefail`.
- Don't loosen a gate to pass: a fail is recorded and explained.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01TPvVBPPLAKNsjK5cEiaGJT`.

## Review Focus

1. Bridge ways that join each other mid-air (ramps on a viaduct): free nodes must take solved heights, never the valley
   floor → `test_ramp_joining_a_viaduct_is_not_grounded` (Task 2).
2. A ground vehicle on a road under a bridge must not be lifted onto the deck; a boat under a bridge stays on water →
   `CamSim.Entity.SurfaceClamp.DeckCeiling` (Task 6).
3. A package with `[buildings]` off but `[bridges]` on must keep `features/bridges/` (the buildings "off" path deletes
   `features/`) → `test_buildings_off_keeps_bridges` (Task 4).
4. Degenerate ways (zero-length segments, a U-turn, two-point ways) must not produce NaN normals or crash →
   `test_sweep_handles_duplicate_points_and_hairpins` (Task 3).
5. With `[bridges]` and no OSM bridges in the box: no tileset, verify passes, rebuild skips →
   `test_no_bridges_in_box_writes_nothing` (Task 4).
