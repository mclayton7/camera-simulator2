# 6A Night Sky Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Night EO whose level and noise follow the real sky (moon, stars, airglow) for the sim date, time and place, with the EO photon count made radiometric (ROADMAP 9.4).

**Architecture:** Pure, unit-tested game-thread pieces (`FEphemeris`, `FNightIllumination`, `FMoonDisc`, `FStarField`, `FCachedExposureBand`, radiometric gain in `FSensorController`) feed `ACamSimEnvironment`, which drives CesiumSunSky's sun, a new moon directional light at atmosphere index 1, a generated IsSky dome material (`M_SkyDome` + `MPC_Sky`) and Lumen's cached-lighting exposure cvar. Scene units stay physical (k = 1). The sensor shader and CPU reference are unchanged.

**Tech Stack:** UE 5.8 C++ (CamSimTest module), UE Automation tests, UE editor Python (material generation), Cesium for Unreal 2.29.1, Python 3 + skyfield (reference values only), uv.

**Spec:** `docs/superpowers/specs/2026-10-16-night-sky-6a-design.md` (read it first; it carries the source-checked findings).

## Global Constraints

- Scene scale k = 1: scene colour / PreExposure = luminance in cd/m²; directional light intensity = lux (top of atmosphere).
- Moon light: `AtmosphereSunLightIndex 1` (never > 1; `bAtmosphereSunLight` true), `bCastShadowsOnClouds` false.
- Never turn az/el into UE rotations with `SetActorRotation` or `FQuat::Rotator()`: convert ENU → UE with `ACesiumGeoreference::ComputeEastSouthUpToUnrealTransformation` (CLAUDE.md gotchas).
- Generated assets (`M_SkyDome`, `MPC_Sky`) are only ever written by `scripts/sky/make_sky_material.sh`; never hand-edit.
- `Content/NonUFS/Sky/bsc5.dat` is git LFS (add the pattern to `.gitattributes`); missing/pointer file → one warning, no stars, never an error (also under `scene.offline`).
- Copyright header `// Copyright CamSim Contributors. All Rights Reserved.`; `#include "CoreMinimal.h"` first; UE naming (`F` structs).
- Tests: `IMPLEMENT_SIMPLE_AUTOMATION_TEST(..., "CamSim.<Group>.<Name>", EAutomationTestFlags::EditorContext | EAutomationTestFlags::ProductFilter)`.
- Build: `scripts/run.sh --build-only` (never pipe through `tee` without `set -o pipefail`).
- Run a test group headless (absolute paths, from repo root):
  ```bash
  /opt/UE/Engine/Binaries/Linux/UnrealEditor "$PWD/unreal_project/CamSimTest/CamSimTest.uproject" \
    -ExecCmds="Automation RunTests CamSim.Environment+Quit" -TestExit="Automation Test Queue Empty" \
    -ReportExportPath="$PWD/.cache/automation-report" -unattended -nullrhi -nosound -nosplash -log -stdout -FullStdOutLogOutput
  ```
  Results: `.cache/automation-report/index.json` (UTF-8 BOM). Update the test counts in CLAUDE.md (two places) at the end.
- Defaults (verbatim from the spec): `night_floor_lux` 0.002; `cached_exposure` day_ev 8, night_ev −6, switch_median_log2 0, hysteresis_ev 2; `transmission` 0.9; `qe` 0.6; `integration_max_ms` = frame period (33.3); `integration_min_us` 10; sun TOA 127,500 lux × (1 AU / r)²; moon K&S with k_V = 0.172.

## Review Focus

- **Clock jumps** (CIGI/control API set a new date, or time runs backwards): moon, stars and band must update on the next tick, not drift. Pinned by Task 8's `ApplySky` running on every clock change (`LastSunMicros = 0` path) — test in Task 8 step 1.
- **Polar sites / moon never rising**: ephemeris must not produce NaN at latitude ±89.9 or at the poles. Pinned in Task 1 (`PolarNoNaN`).
- **Band switch chatter at the threshold** (median oscillating ±0.5 EV around 0 at dusk): no flip-flop. Pinned in Task 4 (`NoChatter`).
- **Radiometric config edge**: a user config that sets `exposure.max_photon_gain_ev` on EO keeps working (ignored + one warning), and an IR mode never becomes radiometric. Pinned in Task 6 (`LegacyKeysIgnored`, `IrStaysCalibrated`).
- **Missing / truncated star catalogue** (LFS pointer, short file): no crash, empty field, one warning. Pinned in Task 3 (`MissingOrTruncated`).

```python
# Copyright CamSim Contributors. All Rights Reserved.
"""Reference sun/moon positions for CamSim.Environment.Ephemeris.* (JPL DE421 via skyfield).

uv run --with skyfield python scripts/sky/make_ephemeris_refs.py
Prints C++ initialiser rows: {Y,M,D,h,m, lat, lon, sunAz, sunEl, moonAz, moonEl, illum, moonKm, lastDeg}.
"""
from skyfield.api import load, wgs84
from skyfield import almanac

CASES = [
    # (UTC y, m, d, h, mi, lat, lon) — Pendleton, SF, Eglin, Yuma, polar, southern, lunar standstill (2025-01), full/new/quarter moons
    (2026, 10, 16, 6, 0, 33.30, -117.35), (2026, 10, 26, 7, 0, 33.30, -117.35),
    (2026, 11, 24, 8, 0, 37.77, -122.42), (2026, 12, 1, 4, 30, 30.46, -86.55),
    (2027, 3, 22, 10, 0, 32.65, -114.60), (2026, 6, 21, 12, 0, 78.22, 15.65),
    (2026, 12, 21, 0, 0, -33.87, 151.21), (2025, 1, 13, 22, 0, 33.30, -117.35),
    (2026, 9, 26, 3, 0, 51.48, 0.0), (2026, 7, 4, 2, 15, 64.84, -147.72),
    (2024, 4, 8, 18, 18, 23.0, -105.0),   # total solar eclipse: sun and moon within ~0.1°
]
ts = load.timescale()
eph = load("de421.bsp")
earth, sun, moon = eph["earth"], eph["sun"], eph["moon"]
for (y, mo, d, h, mi, lat, lon) in CASES:
    t = ts.utc(y, mo, d, h, mi)
    obs = earth + wgs84.latlon(lat, lon, 0)
    sa = obs.at(t).observe(sun).apparent().altaz()
    ma = obs.at(t).observe(moon).apparent().altaz()
    illum = almanac.fraction_illuminated(eph, "moon", t)
    last = (t.gast * 15.0 + lon) % 360.0
    print(f"\t{{{y},{mo},{d},{h},{mi}, {lat}, {lon}, {sa[1].degrees:.4f}, {sa[0].degrees:.4f}, "
          f"{ma[1].degrees:.4f}, {ma[0].degrees:.4f}, {illum:.4f}, {ma[2].km:.0f}, {last:.4f}}},")
```

- [ ] **Step 4: Implement `Ephemeris.h/.cpp`**

Header: exactly the Interfaces block above, with `#pragma once`, `#include "CoreMinimal.h"`, and a doc comment naming the sources. Implementation (all in `double`, angles normalised with a `Norm360` helper):

1. `JulianDayUtc`: `Utc.GetJulianDay()` (UE returns the JD at the instant; check: J2000 test above). TT = UTC JD + ΔT/86400.
2. `DeltaTSeconds(Y, M)`: y = Y + (M − 0.5)/12; for 2005 ≤ y < 2050: `62.92 + 0.32217 t + 0.005589 t²`, t = y − 2000; for 1986 ≤ y < 2005: `63.86 + 0.3345 t − 0.060374 t² + 0.0017275 t³ + 0.000651814 t⁴ + 0.00002373599 t⁵`; outside: clamp y into [1986, 2050).
3. Sun (Meeus ch. 25, low accuracy): T = (JDE − 2451545)/36525; L0 = 280.46646 + 36000.76983 T + 0.0003032 T²; M = 357.52911 + 35999.05029 T − 0.0001537 T²; e = 0.016708634 − 0.000042037 T; C = (1.914602 − 0.004817 T − 0.000014 T²) sin M + (0.019993 − 0.000101 T) sin 2M + 0.000289 sin 3M; true longitude ☉ = L0 + C; ν = M + C; R = 1.000001018 (1 − e²)/(1 + e cos ν); Ω = 125.04 − 1934.136 T; apparent λ = ☉ − 0.00569 − 0.00478 sin Ω; ε0 = 23°26′21.448″ − 46.8150″ T; ε = ε0 + 0.00256 cos Ω; RA/Dec from λ, ε (β = 0).
4. Moon (Meeus ch. 47): L′, D, M, M′, F with the T-polynomials of eqs. 47.1–47.5; E = 1 − 0.002516 T − 0.0000074 T²; Σl, Σr from **Table 47.A** (all 60 rows; multiply terms with M by E, with 2M by E²) and Σb from **Table 47.B** (all 60 rows); add the A1/A2/A3 additive terms; λ = L′ + Σl/10⁶, β = Σb/10⁶, Δ = 385000.56 + Σr/1000 km; apparent λ += Δψ (nutation in longitude, ch. 22 low accuracy: Δψ = −17.20″ sin Ω − 1.32″ sin 2L − 0.23″ sin 2L′ + 0.21″ sin 2Ω, L = 280.4665 + 36000.7698 T); RA/Dec with ε = ε0 + Δε (Δε = 9.20″ cos Ω + 0.57″ cos 2L + 0.10″ cos 2L′ − 0.09″ cos 2Ω). Type both tables in from *Astronomical Algorithms* (2nd ed.) as `static const` arrays of `{D, M, Mp, F, coeff_l, coeff_r}` and `{D, M, Mp, F, coeff_b}`.
5. Sidereal: θ0 = 280.46061837 + 360.98564736629 (JD_UT − 2451545) + 0.000387933 T² − T³/38710000 (mean, Meeus 12.4); apparent = θ0 + Δψ cos ε; LAST = θ0app + LonDeg (east positive), normalised.
6. Topocentric: hour angle H = LAST − RA. Moon parallax (Meeus ch. 40) with ρ sin φ′, ρ cos φ′ from the WGS-84 ellipsoid (b/a = 0.99664719) and HeightM, π = asin(6378.14 / Δ); the sun's parallax is negligible (skip). Alt/az: el = asin(sin φ sin δ + cos φ cos δ cos H); az = atan2(−sin H cos δ, cos φ sin δ − sin φ cos δ cos H), normalised to [0, 360) (compass, from north, east positive). At the poles cos φ = 0: atan2 stays finite (pinned by `PolarNoNaN`).
7. Phase (Meeus ch. 48): ψ = geocentric elongation, cos ψ = sin δ0 sin δ + cos δ0 cos δ cos(α0 − α); i = atan2(R_km sin ψ, Δ − R_km cos ψ) with R_km = R × 149597870.7; illuminated fraction k = (1 + cos i)/2; `MoonPhaseAngleDeg` = i.
8. `SunEnu`/`MoonEnu` = `AzElToEnu(az, el)`; `AzElToEnu` = (sin az cos el, cos az cos el, sin el).

  ```cpp
  struct FNightIlluminationInput
  {
      FEphemerisResult Ephem;
      double CloudCover01   = 0.0;    // CIGI Weather Control coverage / 100
      double NightFloorLux  = 0.002;  // environment.celestial.night_floor_lux
      bool   bSunEnabled = true, bMoonEnabled = true;
  };
  struct FNightIlluminationResult
  {
      double SunToaLux  = 0;          // set on the sun light (atmosphere applies transmittance)
      double MoonToaLux = 0;          // set on the moon light
      double FloorRadianceCdM2 = 0;   // dome floor term = floor lux × cloud factor / π
      double SunGroundLux  = 0;       // expected horizontal illuminance at the ground (tests, log, night_check)
      double MoonGroundLux = 0;
      FLinearColor MoonColor = FLinearColor::White;   // normalised (max channel 1)
  };
  namespace FNightIllumination
  {
      FNightIlluminationResult Compute(const FNightIlluminationInput& In);
      double KastenYoungAirMass(double ElDeg);            // ∞ (returns 40) at/below the horizon
      double Transmittance(double ElDeg);                  // 10^(−0.4 · 0.172 · X), 0 below el −0.5°
      double MoonToaLux(double PhaseAngleDeg, double DistanceKm);   // Krisciunas & Schaefer 1991
      double CloudFactor(double Cover01);                  // 1 − 0.75 · cover^3.4 (Kasten & Czeplak)
  }
  namespace FMoonDisc
  {
      /** Mean over the moon's projected disc of the Lambert shading max(n·s, 0), s = sun direction seen from the moon,
       *  for a phase angle α (0 = full). The dome divides the disc luminance by it so the disc integrates to the
       *  input illuminance: L(p) = E / Ω · shade(p) / MeanShading(α). */
      double MeanShading(double PhaseAngleDeg);
      /** Lambert shading of the disc point (u, v) in [-1, 1]² (u toward the sun's side, v up), 0 outside. */
      double Shade(double U, double V, double PhaseAngleDeg);
  }
  ```

```cpp
IMPLEMENT_SIMPLE_AUTOMATION_TEST(FMoonDiscNormaliserTest, "CamSim.Environment.MoonDisc.Normaliser",
	EAutomationTestFlags::EditorContext | EAutomationTestFlags::ProductFilter)
bool FMoonDiscNormaliserTest::RunTest(const FString&)
{
```

  ```hlsl
  // Copyright CamSim Contributors. All Rights Reserved.
  #pragma once
  float CamSimSkyAirMass(float SinEl)          // Kasten–Young; mirrors FNightIllumination::KastenYoungAirMass
  {
      float ElDeg = degrees(asin(clamp(SinEl, -1.0, 1.0)));
      if (ElDeg <= -0.5) return 40.0;
      return 1.0 / (SinEl + 0.50572 * pow(ElDeg + 6.07995, -1.6364));
  }
  float CamSimSkyTransmittance(float SinEl, float K) { return SinEl < -0.0087 ? 0.0 : pow(10.0, -0.4 * K * CamSimSkyAirMass(SinEl)); }
  // Moon disc luminance along view dir V: 0 outside the disc; Lambert sphere lit from SunDir (mirrors FMoonDisc::Shade).
  float CamSimMoonDisc(float3 V, float3 MoonDir, float3 SunDir, float AngRadius, float LumScale)
  {
      float CosD = dot(V, MoonDir);
      if (CosD < cos(AngRadius)) return 0.0;
      float3 Right = normalize(SunDir - dot(SunDir, MoonDir) * MoonDir + 1e-6);   // toward the sun, in the disc plane
      float3 Up = cross(MoonDir, Right);
      float2 UV = float2(dot(V, Right), dot(V, Up)) / sin(AngRadius);
      float R2 = dot(UV, UV);
      if (R2 > 1.0) return 0.0;
      float3 N = float3(UV, sqrt(1.0 - R2));                    // z toward the viewer
      float3 S = float3(dot(SunDir, Right), 0.0, -dot(SunDir, MoonDir));   // sun seen from the moon, same frame
      return LumScale * max(dot(N, normalize(S)), 0.0);
  }
  ```
