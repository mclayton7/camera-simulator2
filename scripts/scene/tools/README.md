# Gate tools (REALISM R0 gate 5)

| File | What it does |
|---|---|
| `render_check.py` | Launches CamSim on a package (`package PKG`) or on ion (`cwt`), flies the fixed shots (incl. `coast_low`, and `coast_waves` in a second session at Beaufort 5), saves `/snapshot` PNGs, times each shot's terrain readiness (`ready_s`), and fails on any terrain-gate timeout in the log (`gate_timeouts`) |
| `hot_check.py` | CIGI frame-centre heights and HAT/HOT (opcode 24 → 103) vs 3DEP truth; PASS/FAIL at 0.25 m (1 m data) / 1.0 m (1/3″); plus HOT at three sea points vs EGM96 + `sea_level.json` offset (0.05 m, Beaufort 0) |
| `water_check.py` | R1 water gate: open-water leaves vs the raw Sentinel-2 decode, uniformity, and (`--before-hashes`) no leaf without water changed |
| `coast_check.py` | R1 coast gate: package terrain along coast transects vs the drawn sea (EGM96 + `sea_level.json`): offshore below sea, no step at the old 3DEP edge, waterline vs WorldCover, offset vs pyproj; `--before PKG` compares |
| `ndvi_check.py` | R1 chunk 2 NDVI gates: median NDVI per WorldCover class (plausibility), the bias across NAIP's edge (seam; also with the global fit only and unfitted), `--overview` false-colour PNG |
| `road_registration.py` | R2 gate 2: OSM road centrelines vs the package's NAIP (z17), one 2-D shift per 1 km window of the bbox holding >= 1 km of paved motorway..residential road (up to 60, seeded): the zero-sum template road edges minus road interior (OSM roads buffered to `width_m`) correlated against the smoothed luma gradient over +-20 m. Windows are excluded, with a reason, for no road interior, low contrast, a peak at the search edge or no prominent peak. Passes when median \|shift\| <= 10 m over >= 20 used windows and >= 50 % of those tried; reports p90 and the mean (dE, dN) (`--json`, `--overlays DIR`). Aperture limit: a periodic street grid isn't rejected, and a window dominated by one road direction can slide along it or onto a parallel carriageway (the p90 tail) |
| `footprint_iou.py` | R3 buildings gate 2: IoU of hand-traced NAIP building outlines (GeoJSON, lon/lat; `--truth`) against the Overture snapshot's footprints (`--snapshot`, the blob in the fetch cache named by the manifest's `overture_buildings` sha256); each outline is matched to the footprint it overlaps most; prints one line per outline and the median (gate: median >= 0.6, read by a human; exit 0 always) |
| `registration.py` | Phase-correlation shift between a package shot and the CWT shot of the same pose (< 1 px passes) |
| `camsim_session.py` | Shared by the two launchers: package/ion environment, `run.sh --detach` + CIGI host + `/ready`, `stop.sh`; or `--docker IMAGE`: the package bind-mounted read-only at `/data/scene/<name>`, the log from `docker logs` (`.cache/camsim-scene-docker.log`), and for `--offline` a `--network none` container reached through a socat bridge (sidecar `alpine/socat` in its network namespace, Unix sockets, host socat on 127.0.0.1:8080/8888) |
| `offline.sb` | macOS `sandbox-exec` profile blocking ports 80/443 (`render_check.py --offline`, which also sets `CAMSIM_SCENE_OFFLINE=1` and fails on any logged request) |
